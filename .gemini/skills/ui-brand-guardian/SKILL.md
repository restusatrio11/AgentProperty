# Skill: UI Brand Guardian
Ensures the Prime Property design system is strictly followed across all components.

## Brand Assets
- **Primary:** Black (#1A1A1A)
- **Accent:** Gold (#C9A961)
- **Alert:** Red (#B33A3A)
- **Typography:** Inter or Geist (Sans-serif)

## Rules
- **Responsiveness:** Mobile-first approach. Ensure tables are scrollable or card-based on screens <= 640px.
- **Components:** Use Tailwind CSS. Buttons must have a slight gold hover effect if they are primary.
- **Language:** All UI text must be in Indonesian.
